# Архив SQL-скриптов

Файлы в этой папке — история ручных изменений схемы. Они **устарели** и
применять их повторно не нужно: актуальная схема целиком лежит в
`db/schema.sql`, она и накатывается на сервер.

Новые изменения схемы добавляйте в `db/schema.sql` (идемпотентно:
`create table if not exists`, `create index if not exists`, `alter ... if not exists`).
