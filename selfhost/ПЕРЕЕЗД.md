# Переезд CRM на другой VPS

Всё нужное лежит в папке `selfhost/` и в файле `.env` приложения. База — в ночных копиях `/var/backups/crm/`.

## На новом сервере (один раз)

1. Установить PostgreSQL 14+ и Node 20+ (или bun), pm2.
2. Создать пользователя базы `crm` и базу `crm`:
   `sudo -u postgres createuser crm -P` и `sudo -u postgres createdb -O crm crm`.
3. Скопировать папку приложения целиком (со `selfhost/` и `.env`).
4. Поправить в `.env` адрес базы `DATABASE_URL` (если база на том же сервере — `127.0.0.1`).
5. Восстановить данные из последней копии:
   `bash selfhost/restore.sh /var/backups/crm/crm-ГГГГ-ММ-ДД.sql.gz`
   Скрипт покажет количество строк в ключевых таблицах — сверьте со старым сервером.
6. Запустить приложение: `pm2 start ecosystem.config.cjs && pm2 save`.
7. Закрыть сервер: `sudo bash selfhost/server-hardening.sh`.
8. Вернуть расписания (crontab):
   - `30 3 * * * /usr/local/bin/crm-db-backup.sh` (ночная копия; скрипт — из старого сервера, /etc/cron.d/crm-db-backup)
   - `0 8 * * * .../selfhost/monitor.sh >> ~/crm-monitor.log 2>&1` (ежедневный контроль с письмом)
9. Переключить DNS домена на новый IP, выпустить сертификат (certbot/acme.sh).

## Проверка после переезда

- Сайт открывается, вход работает.
- Журнал документов показывает те же номера и итоги, что на старом сервере.
- `bash selfhost/monitor.sh` — все строки «OK».
