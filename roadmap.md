# Замена BigBird — ход работ

## Сделано
- Ручное создание накладной (/shipments/new): продажа/закупка, склад, позиции, автономер.
- Ручное создание ПКО/РКО (/cash/new): тип, статья движения денег, сумма, основание.
- В списке накладных видно состояние учёта (черновик / проведена / отменена), в кассе — сумма документа.
- Печать кассового ордера подписывается как КО-1 (приход) или КО-2 (расход).
- SQL `sql/20260917-posting-and-cash.sql`: проведение накладной пишет движения по складу (продажа списывает, закупка приходует), распроведение и правка позиций пересчитывают остатки, считается себестоимость документа.

## Ожидает пользователя
- Выполнить `sql/20260917-posting-and-cash.sql` в Supabase → SQL Editor (без этого проведение накладной не двигает склад и не сохраняется статья по кассе).
