# План: торговля под разными юрлицами из одной базы

Модель как в bigbird.ru: у каждого юрлица свой логин и свои настройки,
склад/товары/контрагенты общие.

- [ ] Привязка сотрудника (логина) к организации; организация по умолчанию из текущего пользователя

- [ ] Общий хук списка организаций (`src/lib/organizations.ts`)
- [ ] Настройки: несколько организаций (список, добавить, основная, удалить)
- [ ] Настройки: своя касса АТОЛ у каждой организации
- [ ] Документ (карточка): выбор организации, печать/чек от её реквизитов, наследование в дочерние документы
- [ ] Новая заявка: выбор организации, нумерация по маске выбранной организации
- [ ] Журнал документов: фильтр и колонка «Организация»
- [ ] Отчёты (продажи/прибыль/ABC/склад): фильтр по организации
- [ ] КУДиР и кассовая книга: выбор организации
- [ ] SQL: индекс invoices.organization_id + проставить основную организацию в существующие документы
- [ ] Сборка, типы, деплой
