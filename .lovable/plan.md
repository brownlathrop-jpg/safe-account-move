Проверил ключевые замечания по коду проекта. Подтвердилось:

- таблица картинок (`files`) нигде не создаётся — в `db/*.sql` и `sql/migrations/` есть только добавление колонки и индекса. На новом сервере картинки товаров сразу упадут;
- `.env` до сих пор числится в git (`git ls-files` его показывает), хотя в `.gitignore` он есть — правило не действует на уже добавленные файлы;
- в `scripts/deploy.sh` на сервер уезжают только `dist` и `selfhost`; папки `sql` и `scripts` не копируются, миграции не применяются;
- номера версий сессий нет — смена пароля не выкидывает того, кто уже вошёл;
- `РАЗДЕЛЕНИЕ.md` есть только в «Файлах», в репозитории его нет (ссылка в README ведёт в никуда);
- таблица скидок есть в списке разрешённых таблиц кода, но её создания в `db/*.sql` я не нашёл — нужна сверка с рабочей базой.

## Технические детали

- Миграция файлов: `create table if not exists files (id uuid pk, bucket text, path text, content_type text, bytes bytea, workspace_id text, created_at, updated_at, unique(bucket, path))`; затем `update files set workspace_id = (select p.workspace_id from products p where (p.data->>'image_path') = files.path limit 1) where workspace_id is null` — имя поля пути уточнить по `products.tsx`/`db.functions.ts`.
- Версия сессии: `alter table app_users add column if not exists session_version int not null default 1`; `startSession` пишет `v`, `currentUser()` сравнивает `session.data.v` с `row.session_version`, `revokeSessions(userId)` инкрементит. Вызовы в `changePassword`, `resetPasswordWithToken`, `adminSetPassword`, `adminDeleteUser`, `teamRemove`.
- `deploy.sh`: шаги 1/6 build → 2/6 dist+selfhost → 3/6 `tar -cz sql scripts package.json` → 4/6 `node scripts/migrate.mjs` с `DATABASE_URL` из `$REMOTE_DIR/.env` → 5/6 pm2 restart → 6/6 verify.
- Вход: в `auth.server.ts` заменить email-ветку `tooManyAttempts` на `signInDelayMs(email)` = `min(60000, 1000 * 2^(n-1))`, IP-ветка остаётся блокировкой; `tooManySignUps("")` → `true`; `recordAttempt("signup:…")` писать и при отказе из-за занятой почты.
- SSL: вынести `sslOption(url)` в `selfhost/ssl-option.mjs`, импортировать в `scripts/migrate.mjs` и использовать из `pg.server.ts`.
- SSE: в `src/routes/api/realtime.ts` перечитывать `accessibleWorkspaces` по `setInterval` 60 с, `clearInterval` в `cancel()`.
- `migrate.mjs`: писать `checksum = sha256(sqlText)` и сравнивать с уже применённым.
